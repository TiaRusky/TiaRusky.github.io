Le categorie di evidenza aiutano a classificare le domande investigative e gli artefatti da cercare. Le principali categorie sono:

- User Communication
- File Download
- Program Execution
- File Opening
- File Knowledge
- Physical Location
- USB Key Usage
- Account Usage
- Browser Usage

La stessa attività può appartenere a più categorie e può essere rappresentata da diversi artefatti. La classificazione va quindi usata come guida alla ricerca, non come separazione rigida delle evidenze.

Vedi [[Fondamenti di DFIR]] per il contesto generale dell'analisi degli artefatti.
